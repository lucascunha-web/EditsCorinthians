## 📌 Sobre o Projeto

Este site apresenta o elenco principal do **S.C. Corinthians Paulista** em um formato interativo e descontraído. 

> ⚠️ **Aviso Importante / Brincadeira:**  
> Este projeto foi criado puramente para **diversão**! Ao clicar no card de qualquer jogador, em vez de direcionar para uma ficha técnica tradicional, você será redirecionado para um **video edit épico do YouTube** dedicado ao atleta. Aproveite os lances, dribles e defesas da Fiel! 🎬🔥
